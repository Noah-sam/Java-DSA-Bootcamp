## 📖 About This Repository

This repository documents my journey of learning **Java and Data Structures & Algorithms (DSA)**.

It contains:

- 🧠 Java & DSA concepts
- 💻 Practice problems and implementations
- 🎓 Academic coursework
- 🧪 Experimental programs
- 📝 Notes and learning exercises
- 🏆 Problem-solving practice

A major part of this journey follows the **Java + DSA Bootcamp by Kunal Kushwaha**, while the repository also contains programs and assignments from my academic coursework.

The goal is to **learn → practice → solve → build → improve**.
